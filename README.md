# ENCORE. VST

Free plugins for any DAW that runs VST3 on Windows: **Vox** (a whole vocal
chain), **Verb** (reverb), **Equalize** (EQ), **Master** (one-click mastering)
and **Strum** (an acoustic guitar fixer). One installer: tick the ones you want.

**Download:** the newest `ENCORE-VST-<version>-windows-setup.exe` under
[Releases](https://github.com/jimmyrlondo/encore-vst/releases), or from
[ENCORE. Green Room](https://www.londo.tech/encore-studio/vst.html).

- Windows 10 and 11, 64-bit. Mac and Linux are on the way.
- The installer isn't code-signed yet, so SmartScreen may warn you: click
  **More info**, then **Run anyway**.
- After installing, rescan plugins in your DAW (Cubase: Studio > VST Plug-in
  Manager, then Rescan).
- To add or remove plugins later, run the installer again or use **Modify** on
  ENCORE. VST in Windows Settings > Apps. Your presets in Documents\Encore are
  never touched.

This repository holds only the downloads. The source code is at
[jimmyrlondo/sick-and-sad](https://github.com/jimmyrlondo/sick-and-sad), under
the GNU AGPLv3. The same plugins are built into
[ENCORE. Basement Studio](https://github.com/jimmyrlondo/encore-studio).
