# The ENCORE. name and logo

The code here is open source; the brand is not. "ENCORE.", "ENCORE. VST",
"ENCORE. Basement Studio", "ENCORE. Green Room", the plugin names shown with
the ENCORE. mark, the wordmark and the logo belong to Encore Studio.

You're welcome to fork and change the code under its license, but a fork must
use its own name and logo, and must not suggest it's made or approved by
ENCORE. Saying, accurately, that your project is based on the ENCORE. plugins
is fine.
